One line: the funniest error message an AI agent shows when it runs out of tokens mid-sentence.

`main.py` (stdlib only) writes the entry line to the output file resolved
from `ENTRY_OUTPUT`, `OUTPUT_DIR`/`MAKEFUN_OUTPUT_DIR`, or `/output/entry.txt`,
with a validation guard (1–140 characters, single line, not only whitespace)
and mode `0644` on the output file.

Run: `python3 main.py`
